# Audit of Legacy Player v0.7.48 (1 November 2026)

Scope: branch `launcher-phases-1-4` at `78b4416` (clean working tree; no code has changed since 0.7.48 on 13 October,
only Constellation's published copies in `.constellation/`). Read first, as `CLAUDE.md` asks: the `.constellation/`
copies, `docs/canonical/ECOSYSTEM_INTEGRATION.md`, `project.contract.json`, the 12 October audit and its open proposal.

How it was checked: the whole test suite under Python 3.13 on Linux, with Playwright and Chromium so the browser tests
ran too; `ruff` for undefined names, unused code and risky calls; a search of tracked files for keys and tokens;
`tools/validate_repository.py`, `tools/check_links.py` and `tools/check_ui_syntax.js`; and a reading of the update and
download paths, the local web server's host and token checks, and `.gitignore`. Not covered: Windows, the built exe,
real emulators, controllers, routers and play between two networks.

## Results before the fixes

908 tests: 1 failure and 2 errors (6 skipped, all Windows-only).

1. `test_doc_links.test_the_index_lists_every_document` failed: `docs/GITHUB_OWNER.md` (added by a Constellation publish
   on 15 October) was not in `docs/PROJECT_DOCUMENTATION_INDEX.md`.
2. `test_tv_mode` errored on some runs: a key press counts as a user gesture, TV mode then goes full screen, and newer
   Chromium refuses to resize a full-screen window. A test problem, not an app defect.
3. **Self-update (medium).** An empty `.sha256` release file crashed the update with an `IndexError` instead of a plain
   refusal; a malformed one was compared as if it were a hash. Downloads had no size limit and were not checked
   against the size GitHub lists.
4. **Emulator downloads (low).** When GitHub lists no digest for an asset (older uploads), the checksum check was skipped
   with nothing said: a silent fallback, which `.constellation/AGENT_POLICY.md` forbids.
5. **`.gitignore` (low).** `.env.*`, `*.pem`, `*.pfx` and `*.p12` were not covered (`.constellation/REMOTE_WORK.md`
   asks for them). No secret is tracked: the search found none, and the only `.env` file is `deploy/.env.example`.
6. Unused imports in `launcher/app.py`, `launcher/updateall.py`, `launcher/winplace.py` and
   `tools/memory_probe/page_delta.py`. No undefined names or other defects in the app and server code.
7. Docs: ROADMAP's status line still said v0.7.46; README had no "Working remotely" section.

No defect was found in the local web server (loopback, Host check, per-run token compared in constant time), the
release self-update's checksum comparison, or the zip extraction path.

## What changed

All of the above was fixed (see `CHANGELOG.md`, Unreleased). New negative tests: a same-size changed download, empty
and malformed checksum files, and an oversized download are each refused with nothing installed and no update folder
left behind; the emulator installer's log says when no checksum was listed. After the fixes: 911 tests, 6 skipped,
all passing; `test_tv_mode` passed three runs in a row.

## Part 2: decisions closed and addresses made private (same day)

The owner asked for every open decision to be made, and for addresses to be visible to no one. Recorded in
`docs/decisions/ADR-0002_LAUNCHER_SCOPE_AND_ADDRESS_PRIVACY.md`:

- **Governance.** Option A: the launcher is part of `legacy-player`. Proposals 0001 to 0004 are approved as shipped,
  0002 with an amendment, and the libretro frontend is not approved. The governance-name proposal is decided:
  Constellation governs, and Atlas Systems is a different family. `docs/canonical/IDENTITY.md`, `SPEC.md` and
  `CURRENT_STATE.md` were written. Constellation-managed files were not touched; their registry entry has to follow.
- **Addresses.** `LP3-` server codes go through a meeting point (`server/rendezvous.py`) and hold no address of the
  host's computer. Every match is relayed, Dolphin included (`adapters/dolphin/udp_relay.py`). The server refuses
  direct endpoints and host codes. Removed: direct matches, hole punching, UPnP, addresses in codes, the Tailscale
  private link, and a friends service on a player's own computer.
- **Bug found on the way.** A match relayed through an encrypted (TLS) server never worked: Python's ssl module drops
  the outer TLS when a TLS socket is wrapped again. Fixed with a socket bridge, and covered by a regression test.
- **Independent review** of the new networking code (a separate agent that was not told the expected answer). It found
  no path by which one player's address reaches another. It did find problems, fixed here with tests:
  - "New code" could hand out the old token and cut off friends already connected. Rotation now swaps at once and keeps
    carried connections.
  - Friends through the meeting point skipped every per-address throttle. They now share one bucket.
  - The meeting point had no global cap on parked connections.
  - Calls through it had no timeout. They now get the client's timeout and TCP keepalive.
  - A home-network code could travel to friends through the friends service. Only `LP3-` codes are sent now.
  - A broken meeting-point code fell back silently to home-network sharing. It is now refused with a reason.
  - A direct endpoint saved by an older version survived a restart. It is dropped on load.
  - A park that timed out at the moment of pairing could strand a friend.
  - The inner pin was not required when connecting through a meeting point.
  The remaining limits are listed in `docs/canonical/CURRENT_STATE.md`.

Tests after part 2: 886 tests, 4 skipped (Windows-only), all passing under Python 3.13 with Playwright. New suites: `tests/test_rendezvous.py`,
`tests/test_meeting_point_app.py` and `tests/test_dolphin_relay.py`. `tests/test_friends_two_apps.py` now runs two
real app instances through a real meeting point.

## Still open

After part 2, only these remain (`docs/canonical/CURRENT_STATE.md`):

- A meeting point running for released builds (`PUBLIC_SERVER_CODE` is empty).
- Play between two real networks, Dolphin through the relay included.
- Constellation's registry entry for `legacy-player` has to follow ADR-0002 (managed there, not here).
- Full screen at start on Windows, as in the 12 October audit.
- Not verified on real hardware: tray notifications, controller sheets with a physical pad, and the built exe and
  installer. Code signing.
